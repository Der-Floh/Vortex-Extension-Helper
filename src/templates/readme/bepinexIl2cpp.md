## BepInEx

{{gameName}} mods need the IL2CPP build of [BepInEx](https://docs.bepinex.dev). Vortex shows a notification with a link while it is missing. Download the newest `BepInEx-Unity.IL2CPP-win-x64` build from the [bleeding-edge builds](https://builds.bepinex.dev/projects/bepinex_be), drop it on Vortex's Mods page, enable it and deploy.
